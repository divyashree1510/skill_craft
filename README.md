Interactive Navigation Menu
Overview
This project demonstrates an interactive and responsive navigation menu built using HTML, CSS, and JavaScript. The navigation bar remains fixed at the top of the page, changes its appearance when the user scrolls, and provides interactive hover effects on menu items for an enhanced user experience.
Features
Fixed navigation menu visible at all times
Dynamic navbar style change on scroll
Hover effects on navigation links
Smooth scrolling between sections
Active menu item highlighting
Responsive design for different screen sizes
Modern and user-friendly interface
Technologies Used
HTML5
CSS3
JavaScript (ES6)

How It Works
Fixed Navigation Bar
The navigation menu uses CSS position: fixed to remain visible at the top of the page while scrolling.
Scroll Effect
JavaScript detects the user's scroll position and dynamically adds a CSS class to the navigation bar, changing its background color, padding, and shadow effect.
Hover Effect
CSS hover selectors are used to provide visual feedback when users move the cursor over navigation links.
Responsive Design
Media queries ensure the website adapts smoothly to mobile, tablet, and desktop screens.
